# 决策规则速查 — 李大霄投资战略（第三版）

| 能力 | 一句话规则 |
|---|---|
| 大势位置—操作姿态总纲 | 按市场位置匹配三阶段操作姿态——历史大底需勇气买入、中间区域需坚持持有、历史大顶需淡泊退出，并以"第一时间认错止损"兜底。 |
| 历史大底五维识别 | 用估值、股债差、风向标、情绪极值、供给与政策五维对照历史大底区间，多维同向才判定"底部区域"，不猜点位。 |
| 顶部、泡沫与转弱信号识别 | 以估值极值、供给减持、杠杆与做空工具、巨量不涨、情绪与事件提前量核对顶部/泡沫信号并分级预警，按荔枝/苹果节奏定退出。 |
| 风向标与跨市场资金跟踪 | 产业资本增持与国家队出手＝底部区域倾向，巨量减持与社保撤退＝顶部区域倾向，多信号同向才下区域结论。 |
| 股债差逆向配置与高息牛判别 | 股债差＝优质股股息率−10年/50年国债收益率；历史高位＝股票相对极便宜（配置良机），历史低位＝弃债追股危险。 |
| 资金供需流量与政策研判 | 引资速度＞融资速度则涨、等于则平、小于则跌；政策工具停启与组合拳方向是A股研判的核心权重。 |
| 入市资格自检与散户进阶 | 只用30—50年不用且能承受波动的余钱入市；先按基金五步骤逐级毕业再碰个股，家庭内一个司令。 |
| 策略定位与能力自检 | 投机须"投机氛围+投机技巧"双条件同时成立才选，投资须"投资条件+投资水平"双条件同时成立才选；两者都不满足就多坐轿子、不坐庄、只赚上市公司创造的钱。 |
| 选股优先与排除 | 选股自上而下按"全球最好→全国第一→全国第二"排序、切勿倒着选；先排除高估五类、ST/退市与不分红的"铁公鸡"，再在低位拥抱最低估最优质的蓝筹龙头。 |
| 情绪逆向与信息甄别 | 舆论与生活指标一边倒到极值时事情往往朝相反方向转化——共识作反向提示，信息源按"先查机构盈利模式、医德重于医术、10年言论检验"评级；结论必须与估值信号交叉。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
